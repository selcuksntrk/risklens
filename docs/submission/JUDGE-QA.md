# Judge answers

| Question | Answer and evidence |
|---|---|
| Is this a real home? | No. The demo uses Hypersim synthetic interiors, explicitly attributed under CC BY-SA 3.0. |
| Why not a single image prompt? | We combine concept planning, temporal object tracking, exact-frame evidence, source lookup and comparison safeguards. The same-input comparison measures tradeoffs; it does not automatically establish superiority. |
| What does SAM contribute? | Candidate tracks and object-linked evidence. See measured tracking support and inspect the boxes. A box alone does not prove a finding correct. |
| What happens with hidden anchors? | They are unknown. The report requests checking instead of treating an unseen connection as absent. |
| Did it verify a real physical precaution? | No. Positive physical-change validation is unmeasured. The submission includes limited synthetic negative controls. |
| Does the identical-file test use AI? | No. A SHA-256 match prevents treating the original file as proof of a new change. Other cases may invoke models; the record distinguishes them. |
| What is the accuracy? | No real-home accuracy is claimed. Five reused synthetic scenes provide development regression. Human matching is required before reporting correctness metrics. |
| Is FEMA approving the advice? | No. Links document the sections read by the model. The system withholds suggestions that fail its source checks; this is not expert validation. |
| Can it be wrong? | Yes. It samples views, can miss relationships, and has limited cross-clip identity. Explicit unknowns and safeguards narrow claims but do not eliminate errors. |
| What does it cost? | The evaluation lists measured per-run time/cost and failures. Application accounting is not a provider invoice. The existing $15 daily cap and bounded queue remain in place. |
| What about privacy? | Public examples are explicitly packaged licensed scenes. New scans belong to a browser session; source media is retained for 7 days and reports/evidence for 30, with deletion and access controls. Models process media remotely. |
| Who will use or pay for it? | The intended user is someone preparing a living space. Adoption and willingness to pay are not validated; a consented, expert-reviewed pilot is future work. |
