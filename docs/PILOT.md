# Evidence-gated pilot backlog

These are future work packages, not implemented or validated product claims. Start after the hackathon's negative controls, privacy checks and real-room acceptance records exist.

| Package | Next implementation / study | Exit evidence |
|---|---|---|
| Expert labels | Independent expert review of observation, relation, priority, action/source support and local installation conditions; preserve disagreements | Critical error taxonomy and corrected labelled examples |
| Cross-clip identity | Candidate appearance + surrounding context; select thresholds on separate validation rooms | More correct confirmations without increased false confirmation on similar objects |

| Commercial discovery | Interviews with site management, preparedness programs and loss-prevention stakeholders | Named use case, responsible distribution owner and evidence of willingness to pay |

## Expert annotation record

Use a private JSON record per finding with anonymous room/object IDs, source clip hashes, exact visible observation, unknowns, relation, recommended action, section/page, whether the cited text supports the action, local conditions needed, expert decision, disagreement reason, review timestamp and reviewer qualification. Do not label hidden anchorage as absent. Preserve model answers separately from expert labels.

## Volunteer record

Obtain explicit consent and explain media processing/deletion/access before capture. Record which suggestions the user understood, the action actually completed, why they stopped, whether they re-filmed, and whether the visible change could be evaluated. Store identifying contact details separately from anonymous study records. A completed precaution the user understands is the primary outcome; model/objects counts are not success measures.

## Auditor gate

First scope: a second opinion about recommendation–source consistency only. It cannot close findings or produce `fixed`. Record model, provider and task. Compare extra errors caught, false alarms, elapsed time and cost on a frozen set before inclusion. No contributor model on real-home media. An open-weight auditor has not been added to the core path.

## Performance and expansion

Measure bottlenecks before comparing reasoning effort, keyframe strategy or fixer parallelism. Hold inputs and labels fixed. Reject speed changes that worsen safety-relevant errors. Fire/water hazards, PDF reports, more languages and insurance decisions are outside the current delivery; expand only after earthquake workflow and user-completion evidence justify it.
