# Release and rollback runbook

1. Preserve local user changes. Run backend tests, frontend tests/lint/build. Review the diff for secrets and private media. Public example packaging must pass the licensed-source hash check; personal scans cannot be promoted by an ID alone.
2. From a clean temporary source copy, run `uv sync --frozen --no-dev` and `npm ci`, then build. If network/package access prevents this check, record it as pending rather than claiming reproducibility. Do not include `.env`, `scans`, private eval media or existing virtual environments in the clean copy.
3. Export pinned production dependencies: `uv export --frozen --no-dev --no-hashes --format requirements-txt --output-file deploy/requirements.txt --project backend`.
4. Run `python3 scripts/build_release.py`. Save `VERSION`, `release.json`, the application source snapshot and the prior working release. Build/package backend and frontend together. The source hash intentionally includes dirty working-tree source, so an uncommitted change cannot hide behind an old Git SHA.
5. Package a current completed synthetic example with `python3 scripts/package_example.py scans/APPROVED_RUN /path/to/approved/clip.mp4`. Run `backend/.venv/bin/python scripts/fetch_example.py` for a fresh licensed download. The fetch tool checks all 100 original JPEG hashes against the committed licensed-source manifest, then records the encoded clip hash. The packager accepts that verified manifest or the original approved clip hash. Different ffmpeg versions can produce different MP4 bytes. Never bypass source checks for arbitrary media.
6. Deploy with the Modal CLI: `modal deploy deploy/modal_app.py`. Keep `max_containers=1` and one server process: the queue/ledger lock is not distributed. `RISKLENS_MIN_CONTAINERS=1` is optional for the judging window and has hosting cost. Secure cookie mode is set in deployment code. Existing secrets stay server-side.
7. After deployment: GET `/api/health` and match `VERSION`; GET homepage and verify matching frontend release; GET `/api/examples`; open the completed example without inference. Start one live sample, observe completion or an honest incomplete result, and record duration/cost. Upload a private test clip in browser A. In browser B, check list/report/files/events/history/verify/fixcard/delete are rejected. Check attempt-specific verification status. Delete browser A's scan and confirm files do not reappear.
8. Only call the release a demo candidate after actual outcomes are recorded. Real-phone tests and negative real-room controls remain separate release evidence. Preserve failed cases. Do not make unmeasured performance claims.

Rollback: redeploy the saved previous source/build release against the same Modal Volume. Do not delete or migrate user data. Because old releases may lack ownership checks, never roll back to an insecure public uploader: disable public upload or deploy the last privacy-safe release. Historical reports open through a read-only adapter; no bulk migration rewrites evidence.

Operational checks during judging: health/version, job counts, terminal error counts by class, durations, budget/unknown-usage totals and expired-content cleanup. Avoid raw images, narration, paths or model descriptions in service logs. Restarted queued/running jobs are marked interrupted by persistent status; retry requires a new explicit request.

Raw cleanup is startup/hourly while active. Moving it to an independent scheduler and introducing a persistent multi-worker queue are pilot work. Local administrative recovery: `python -m app.cli claim-legacy LEGACY_ID --owner-from-scan KNOWN_OWNED_SCAN_ID`; only an operator with filesystem access can run this. It never grants web ownership by knowledge of a scan ID.

Durability: atomic snapshots fsync before rename; the Modal deployment binds persistence to `Volume.commit()` before model dispatch and after deletion. This is deliberate: [Modal documents explicit commits and periodic background commits](https://modal.com/docs/guide/volumes). A failed commit fails the operation instead of claiming a durable accepted job.
